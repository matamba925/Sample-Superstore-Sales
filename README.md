Sample Superstore Profitability Sample-Superstore-Sales
This repository contains a comprehensive exploratory data analysis (EDA) and interactive dashboard project focused on resolving a classic retail paradox: consistent top-line revenue growth paired with highly volatile net profits.
Using Python (Pandas) for data cleaning and Tableau / Power Tableau for interactive visualizations, this project uncovers the root causes of margin bleed—specifically highlighting the "Discounting Trap" and geographic inefficiencies—and provides data-driven recommendations to stabilize bottom-line performances
